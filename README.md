# Isometric cube game

A Godot 4.6 GDScript sandbox with mouse aiming, slash attacks, and shooting.

Open `project.godot` in standard Godot and press **F5** for the main menu.

- **WASD**: move
- **Mouse**: aim
- **Left click / hold**: shoot
- **Space**: slash
- **Esc**: pause

Includes saved settings and progress, Continue, achievements, toast notifications, music and SFX controls, fullscreen mode, and six UI languages. No C# or .NET required.

See [Game systems](docs/GAME_SYSTEMS.md) for implementation, save behavior, and tests. Audio reused from the DMG starter template is attributed in [assets/audio](assets/audio/README.md).
